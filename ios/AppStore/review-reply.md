2. Purpose and target audience
Carrel is a flashcard (spaced-repetition) app for students and self-learners, for example people studying vocabulary, exam material, or history. The problem it solves: users want to read, study, and write their own study cards in one place, with cards rendered from HTML/CSS templates so they look exactly as the user designed them. Its value is a readable card view, a search with tag/deck filters and relevance ranking, a study mode with spaced-repetition scheduling, and an in-app editor for cards and card templates.

3. Setup and access
No login or credentials are needed. On first launch the app preloads three sample cards and shows a short tutorial. Main features: tap a card in the list to read it; the graduation-cap button (bottom-left) opens Study, then tap 開始 (Start) to begin, 答えを見る (Show answer) and grade with × △ ○ ◎; the bottom-left menu has 新しいカード (New card); Settings (⋯ menu › 設定) contains the optional 外部ファイルの同期 (external file sync) feature, which lets the user choose a folder on their own device or iCloud Drive to read and write card files in the .anki2 format. No sample files are required.

4. External services
None. The app does not connect to any server operated by us, has no analytics or advertising SDKs, and requires no account. The only network access that can occur is when a user's own card template references an external image or script URL, which is fetched to render that card. Optional file sync uses the system file picker and the user's own storage (for example iCloud Drive) through standard iOS document APIs.

5. Regional differences
None. The app functions identically in all regions. The UI is currently in Japanese.

6. Regulated industry / protected material
Not applicable. Carrel is a general-purpose flashcard app and contains no third-party protected content. The card file format (.anki2) is an open SQLite-based format; "Anki" is a trademark of Ankitects Pty Ltd, and Carrel is an independent app that is not affiliated with Ankitects and does not connect to AnkiWeb.
