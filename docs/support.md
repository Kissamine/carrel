# Carrel サポート / Support

Carrel は、見て・学んで・作れる暗記カードアプリです (iOS / iPadOS / macOS)。

## 困ったときは
- 使い方: アプリ内の 設定 › 使い方ガイド (チュートリアルもここから再表示できます)
- 不具合の報告・要望: https://github.com/Kissamine/carrel/issues
- プライバシーポリシー: https://github.com/Kissamine/carrel/blob/master/docs/privacy.md

## よくある質問

**カードはどこに保存されますか？**
端末の中です。設定で「外部ファイルの同期」のフォルダ (iCloud Drive など) を選ぶと、そのフォルダにも .anki2 形式で書き出され、ほかの端末やエディターと共有できます。

**同期をやめたい**
設定 › 外部ファイルの同期 › 同期を解除。アプリ内のカードはそのまま残ります。

**Anki との関係は？**
Carrel は Ankitects とは無関係の独立したアプリで、AnkiWeb には接続しません。カードのファイル形式 (.anki2) に互換性があるだけです。
